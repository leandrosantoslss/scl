# Sicoob (spec técnica)

Base URLs: produção/homologação conforme credenciais do convênio cooperado.
OAuth client_credentials com scopes oficiais; PIX key e conciliação conforme
os endpoints no convênio; mTLS/certificado pelo provedor oficial.
Boleto: emissor com idempotência própria e cancelamento no provedor.
Rate limits / retry / status mapping / webhook assinado: documentação oficial.

Specs detalhadas de endpoints exigem acesso à documentação oficial e credenciais
de homologação pelo operador.
