# Sicredi (spec técnica)

Base URLs: oficial homologação/produção; credenciais governamentais por cooperativa.
OAuth: API REST com são comprovadas as exigências no convênio (mTLS/certificado, scopes).
Boleto e PIX conforme o convênio contratado.
Idempotência e assinatura dos webhooks: mapear endpoints oficiais.
Status externo → status interno: issued/paid/cancelled/unknown.

Specs de adaptador exigem acesso à documentação oficial e credenciais de homologação.
